# Sahafi frontend storyboard

Keep the warm restaurant ledger identity and bilingual content.

| Surface | Desktop | Mobile | Awwwards reference |
| --- | --- | --- | --- |
| Ledger | Emphasize outstanding balance, status and filtered count | Stable balance block in stacked records; wrapped status filters | [Shop Local RI filtering](https://www.awwwards.com/inspiration/product-listings-filtering-shop-local-ri) |
| Payment entry | Explicit recorded-payment preview and retained focus | Bottom sheet fits visible keyboard viewport; touch-size fields | [Eduard Bodak form fill](https://www.awwwards.com/inspiration/form-fill-eduard-bodak-portfolio) |
| Confirmation | Short surface/toast arrival; monetary values appear immediately | Same concise feedback, reduced-motion support | [Eduard Bodak form fill](https://www.awwwards.com/inspiration/form-fill-eduard-bodak-portfolio) |
| History | Readable row focus and balances | Existing cards and customer history retained | [Shop Local RI filtering](https://www.awwwards.com/inspiration/product-listings-filtering-shop-local-ri) |

No payment allocation, rounding, data key, stored format or external sending changes. Record and payment mutations are tested on local sample data only. Production remains separate.
